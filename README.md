# StudyFlow

StudyFlow is a personal study operating system built for students who want to combine JEE preparation, HSC learning, competition planning, and research in one place.

## Key ideas

- JEE tasks can include direct video links and a visual yellow progress state during study.
- HSC tasks can track reading and revision using a red → yellow → green system.
- Competition progress is tracked as: red (not submitted), yellow (results pending), green (won), orange (learn from it).
- The planner automatically generates revision cycles using spaced repetition techniques.
- Research work is grouped separately to support long-term human capital growth.

## Included study methods

- 2-3-5-7 review intervals
- Standard review windows: Day 1, Day 3, Day 7, Day 14, Day 30
- Active recall + Leitner-style revision flow
- Progress tracking for JEE, HSC, competition, and research

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Notes

This version is a polished single-page app with local browser storage so you can try it instantly without a backend.
